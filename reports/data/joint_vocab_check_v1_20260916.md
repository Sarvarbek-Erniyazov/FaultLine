## Observed, not asserted: the text checkpoints carry one row outside the region

The M2 text-only checkpoints embed `S2_text_seed1.pt` 32,769 rows, `S3_text_seed1.pt` 32,769 rows. The text shards append a local `<sep>` at id 32,768, one past the tokenizer, so a text checkpoint has one row more than the text region holds. That row has no joint id in `[1184, 33952)`. The joint `<sep>` is the structural token at id 8. A joint model initialised from a text checkpoint must map text rows `0..32,767` to joint ids `1,184..33,951` and row `32,768` to id 8, not append it. This does not bear on ADR-0003: the region itself is neither over nor under full.
